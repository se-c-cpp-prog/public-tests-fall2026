## Настройка тестирующей системы

Порядок настройки локального тестирования:

1. Убедиться, что у вас установлены [`git`](https://git-scm.com/), [`python`](https://www.python.org/). Если у вас установлен [Debian](https://www.debian.org/)/[Ubuntu](https://ubuntu.com/), то вам необходимо также установить пакет `python3-venv` через пакетный менеджер `apt`:

    ```bash
    sudo apt install python3-venv -y
    ```

2. Склонировать этот репозиторий:

    ```bash
    git clone https://github.com/se-c-cpp-prog/public-tests-fall2026.git
    ```

3. Находясь в корневой директории этого репозитория выполнить в терминале команду:

    ```powershell
    powershell .\Util-Init-Testing-System.ps1
    # на Windows (PowerShell)
    ```

    ```bash
    ./util-init-testing-system.sh
    # на Linux/macOS
    ```

4. Перед запуском тестов вам необходимо активировать созданный в пункте 3 [виртуальную среду Python](https://docs.python.org/3/library/venv.html):

    ```powershell
    .\.venv\Scripts\Activate.ps1
    # на Windows (Powershell)
    ```

    ```bash
    source ./.venv/bin/activate
    # на Linux/macOS
    ```

5. Для обновления тестов находясь в корневой директории этого репозитория выполнить в терминале команду:

    ```bash
    git pull
    ```

6. Для обновления тестирующей системы (о чём будет сказано в чате курса) находясь в корневой директории этого репозитория выполнить в терминале команду:

    ```powershell
    powershell .\Util-Update-Testing-System.ps1
    # на Windows (PowerShell)
    ```

    ```bash
    ./util-update-testing-system.sh
    # на Linux/macOS
    ```

## Запуск тестов

Ниже представлена таблица доступных для тестирования (как локально, так и автоматически в репозиториях) работ с названием набора тестов.

| Задание | Набор тестов                 |
|:--------|:-----------------------------|
| A + B   | [`SumTest.py`](./SumTest.py) |

> [!NOTE]
> Вы можете запустить команду `python <набор тестов> --help` для получения справочной информации.

Тестер выполняет тестирование программы методом "чёрного ящика", то есть на вход *input* программа выдаёт какой-то выход *output*, который должен быть правильным с точки зрения текущего теста. Необходимым и достаточным параметром любого набора теста является:

  * `--program <path/to/executable>` - путь к исполняемому файлу. Пример запуска:

    ```bash
    python3 ./SumTest.py --program ./a.out
    ```

Поскольку отсутствие оптимизации при сборке (например, с ключом `-O0 -g` для дебага программы) и [санитайзеры](https://clang.llvm.org/docs/AddressSanitizer.html) могут замедлить вашу программу, то имеет смысл установить множитель максимального времени исполнения процесса на все тесты:

  * `--timeout-factor <float>` - множитель максимального времени исполнения порождённого процесса программы (по умолчанию - `1.0`).
